# Сайт храма святителя Спиридона Тримифунтского (Пенза)

Статичный одностраничный сайт без сборки: `index.html` + `styles.css` + `main.js`.

## Структура

```
index.html          — разметка страницы (семантические header/nav/main/section/footer, schema.org/Church, Open Graph)
styles.css          — стили; цвета, шрифты и отступы вынесены в CSS-переменные в начале файла
main.js             — мобильное меню, кнопка «Скопировать реквизиты», загрузка data/*.json
data/schedule.json  — расписание богослужений
data/news.json      — новости прихода
images/             — фото и графика (hero.jpg/.webp — первый экран, og.jpg — превью для соцсетей, favicon.svg)
reference/          — исходные макеты (desktop 1440px, mobile 390px)
```

Брейкпоинты: ≤ 767px — мобильная раскладка, 768–1199px — планшет, ≥ 1200px — десктоп; контейнер до 1440px.

## Как обновлять контент

- **Расписание** — правьте `data/schedule.json`: поля `day`, `time`, `title`, `holiday` (праздничная строка подсвечивается). Поле `updated` в формате `ГГГГ-ММ-ДД` выводится под таблицей.
- **Новости** — `data/news.json`: `date` (`ГГГГ-ММ-ДД` или готовая строка), `title`, `text`, `url` (пост ВКонтакте), `image` (путь к картинке в `images/`). Показываются первые три.
- Если JSON недоступен (например, страница открыта как файл с диска, а не с сервера), остаются заглушки из `index.html`.

## Что ещё ждёт данных от прихода

- Фото настоятеля и ковчега с частицей мощей (`[Фото настоятеля]`, `[Фото: ковчег…]` в `index.html`).
- Реальные строки расписания и новости в `data/`.
- Подтвердить формулировку назначения платежа «Пожертвование на строительство храма».
- После публикации указать абсолютный адрес сайта в `<link rel="canonical">`, `og:image` и `url` в schema.org (помечено `TODO` в `index.html`).

## Локальный просмотр

Любой статический сервер из корня проекта, например:

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File .claude/serve.ps1 -Port 8080
```

или `python -m http.server 8080`, затем открыть http://localhost:8080/.
